# Nucleora

A design studio for coding DNA and mRNA constructs. Each of its 517 documented calculations carries a provenance record: the formula, the code path, the sources, and whether the result is a heuristic (239 are labelled as heuristics, in the interface, where you read the number).

- **Free browser calculators:** [primer Tm](https://nucleora.org/tools/primer-tm-calculator/), [reverse complement](https://nucleora.org/tools/reverse-complement/), [six-frame translation](https://nucleora.org/tools/dna-translation/), [GC content](https://nucleora.org/tools/gc-content-calculator/), [CAI](https://nucleora.org/tools/codon-adaptation-index/), [codon optimization](https://nucleora.org/tools/codon-optimization/), [Golden Gate overhang fidelity](https://nucleora.org/tools/golden-gate-overhang-fidelity/), [oligo properties](https://nucleora.org/tools/oligo-properties/) and a [restriction site finder](https://nucleora.org/tools/restriction-site-finder/). They compute in your browser and send the sequence nowhere.
- **Codon usage reference:** per-organism tables tallied from NCBI RefSeq, with the [method](https://nucleora.org/codon-usage/methods).
- **The application:** hosted at app.nucleora.org, in closed testing. [Request access](https://nucleora.org/#newsletter).

Nucleora is research and design software. It is not a medical device, and a construct designed in it still needs bench validation and your institution's biosafety review.
